# Support

## Questions and usage help

Use [GitHub Discussions](https://github.com/3x-haust/oh-my-design/discussions) for setup questions, workflow advice, and ideas that are not yet actionable bug reports. Search existing issues and discussions first.

For a reproducible defect, open a bug report and include the OMD version or commit, Node version, operating system, host (Codex, Claude Code, or Pi), command, expected behavior, and a minimal reproduction with synthetic data.

This community project does not promise response or resolution times.

## Security

Do not disclose vulnerabilities, credentials, private design files, or live exploit details in an issue or discussion. Follow [SECURITY.md](SECURITY.md) and use the repository Security page's private reporting flow.
