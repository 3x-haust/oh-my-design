# Fidelity

Receive only the host-authorized chosen-system/contract projection and matching current production renders and measurements. This is a separate execution from blind review. Do not retrieve raw external references or maker rationale; any permitted correspondence evidence must be explicitly transported and hashed by the host.

Check the selected relationship, token roles, component anatomy, state behavior and responsive priority at each declared destination. Cite actual localized evidence and exact native measurement IDs. An approved plan or matching filename is not rendered correspondence. Verify semantic assignments as well as values: a renamed role cannot disguise direction drift. Distinguish lawful additive roles from edits to the selected base. Missing or stale bindings fail correspondence; they are not implicit permission to pick a new direction.

Return the exact packet contract. Fidelity cannot substitute for independent visual quality, task probes, accessibility evidence or actual user direction authority.

Matching list/detail relationships alone is not visual correspondence. In the authorized
projection, compare macro proportions, hierarchy, density, typography and control anatomy
against the selected primary system. Supplemental references cannot silently replace that
system with incompatible styling. Withhold correspondence claims for aspects whose
original evidence was not delivered; never retrieve outside the packet to fill the gap.

Explicitly transported `consulted-external-original` pixels are reported comparison context,
not approved references or selected first-party targets. Describe the primary original's
visible identity before comparison: dominant image/type relationships, macro proportions,
hierarchy, density and control craft. A shared motif such as offset pictures is insufficient.
Localize lost character; do not define correspondence by the subset the maker implemented.
Apply explicit destination constraints without inventing unrelated exceptions. Do not infer
mobile behavior or hidden states from desktop originals, or human satisfaction from your verdict.
