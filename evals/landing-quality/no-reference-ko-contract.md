# URL-free Korean landing development fixture

This is public development evidence, not a held-out evaluation. Run `no-reference-ko.md` unchanged
in a fresh project containing the current first-party OMD README and the current frozen OMD package.
The entire user input is its one sentence. Do not append an execution prompt that restates desired
quality, reference research, motion, responsiveness, verification or owner sequencing. Those must
come from OMD's installed defaults. Do not add selected sites, reference URLs, gallery names,
screenshots, search results, palette, layout, motion recipe or previous studies. Preserve the earlier
English studies and the interrupted four-sentence Korean attempt separately. This contract is for
the outside evaluator; do not place it in the native project's input or prompt.

Use only native OMD roles, skills, publishers and browser evidence, with the user's model inherited.
The fixture does not authorize repository publication, deployment, global settings changes or
product-fact invention. It asks for a working local page, not a translated screenshot or hero study.

Inspect native image-tool discovery before a method choice. With the capability available, unsettled
marketing should generate actual first-party image studies without extra user wording, compare their
visible results and reconcile the selected direction with approved references/copy/type before code.
Retain actual generation calls and returned images; HTML studies are not image-generation evidence.
An observed missing tool remains a precise capability limitation, not an excuse to claim images ran.

Inspect whether the native run discovers references itself, including useful same-language type
and current high-craft site evidence, and separates task anatomy from visual craft and motion. The
bare request does not supply a country aesthetic or require a particular gallery. Native captures must
support the retained decisions; search snippets and a self-reported query list are not sufficient.
Record actual search activity separately from the Scout-disclosed provenance, without claiming that
free-text query records are cryptographic search receipts. No reference or candidate quota applies.

Judge the real Korean copy, typography, desktop/mobile composition, complete-page continuity and
working interactions. Inspect any selected motion at multiple scroll/interaction states plus its
settled and reduced-motion result; study and selection are not automatic authority for decorative
motion. Check exact install-copy success/recovery when copying is implemented, keyboard access, no-JS reach,
320px reflow and 200% zoom. Keep these requirements out of user-facing page text.

Finish through the native Hand transaction, current source-linked browser evidence, isolated final
review pair, final-v2 and terminal preflight. Functional tests do not establish visual quality;
reference fidelity does not establish human equivalence or native cultural correctness.
