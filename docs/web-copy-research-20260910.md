# 웹 카피 조사와 적용 기록

2026-09-10. 대상은 README를 바탕으로 만드는 OMD 한국어 랜딩페이지다.
사용자가 기존 카피를 거절하고 웹 카피라이팅 원칙·공식을 조사해 적용하도록 요청했다.
이 기록은 그 개발 과정이며, 전환율이나 사용자 선호도 향상을 입증한 보고서가 아니다.

## 기존 카피의 문제

현재 원고의 제목은 “디자인 결정마다 근거를 따집니다.”이고 바로 아래 문장은
“사용자가 선택한 모델을 그대로 사용합니다.”였다. 둘 다 출처로 뒷받침할 수 있지만,
첫 문장은 내부 작업 태도를, 둘째 문장은 실행 조건을 말한다. 독자가 이 도구로
무엇을 할 수 있는지와 자신의 작업에 왜 필요한지가 두 문장 사이에 빠져 있다.

본문도 방법 선택, 검토, 기록, 내부 에이전트 수를 중심으로 구성됐다. 사실 검증과
문법 검사를 통과했다는 이유만으로 이 설명을 좋은 랜딩 카피로 인정하지 않는다.
사용자의 이번 거절은 기존 문구 선택을 다시 여는 근거다.

공식은 검증된 상품 성과가 아니라 작성 가설이다. 이 랜딩에 적용할 조합은 실제
원고와 독자 과업으로 선택한다. 모든 공식을 쓰는 것이 목표가 아니며, 필요한
조건을 충족하지 못하는 공식은 채택하지 않는다. 특히 현재는 실제 전후 성과나
고객 증언이 없으므로 이를 새로 만들어 BAB나 사회적 증거를 채우지 않는다.

## 하네스 반영

- `core/theory/web-copy.md`: 7개 공식의 쓰임과 제외 조건, 독자 가치와 근거를 연결하는
  작성 절차, 한국어 편집, 행동 예측, 독립 이해도 점검을 추가했다.
- Writer와 OMD-humanize는 마케팅 원고를 쓸 때 이 자료를 읽는다. 실제 바뀐 문장과
  순서는 기존 카피 덱의 Humanize audit 안에 기록한다. 별도 승인 단계를 만들지 않았다.
- copy-editor는 작성자의 설명보다 실제 원고를 먼저 읽고, 제품·독자·도움이 되는
  과업·주장의 근거·다음 행동을 자기 말로 요약한 뒤 사실과 대조한다.
- 원래 원고를 유지하기 위해 레이아웃이나 과거 서체 승인을 핑계로 삼지 않는다.
  원고 변경에 영향받는 검토·서체·구성·렌더 증거는 다시 만들어야 한다.
- 기존 이론의 “2020년에도 1997년의 정확한 비율이 같았다”와 “문헌 전체에서 가장 큰
  효과”라는 과도한 해석도 수정했다. 2020년 자료는 스캔 행동의 지속을 보고하며,
  독서량이 과업과 동기 등에 따라 달라진다고 설명한다.
  [NN/G 2020](https://www.nngroup.com/articles/how-people-read-online/)

## 현재 검증 상태

관련 146개 테스트, `npx tsc --noEmit`, `npm run build`가 통과했다. 테스트는 지침의
연결과 소유권·범위를 확인하며, 카피의 설득력을 자동으로 증명하지 않는다.

기존 실행을 종료하고 수정 패키지로 동일 작업을 재개했다. 새 입력은 사용자의
카피 거절·웹 조사 요청 그대로이며, 별도의 숨은 문구나 디자인 정답은 주입하지 않았다.
재개 실행이 이전 시안 선택으로 돌아가 중단한 뒤, 새 대화에서 원래 제작 요청과
최신 카피 요청만 전달했다. 그 실행은 웹 자료를 직접 확인하고 Writer를 호출했다.

## 첫 실제 재작성 결과

Writer는 세 가지 도입 전략을 작성·비교하고 다음 문구를 선택했다.

> 코딩 에이전트에 디자인 검토까지 맡기세요.
>
> OMD는 레퍼런스 조사, 카피·서체 검토, 화면 비교를 작업에 맞춰 조합합니다.

이전 제목은 작업 태도를, 새 제목은 독자가 맡길 수 있는 일을 말한다. 모델 유지
조건은 호스트 이름 옆으로 옮겼다. 방법 설명의 반복 대신 Figma 원본이 있을 때
구조 대안을 생략할 수 있다는 구체적인 조건을 넣었다. 여섯 스킬은 유지하되 내부
에이전트 수와 CLI·팩 목록은 독자용 소개에서 제외했다. 설치 안내에는 기본 설치가
영향을 주는 호스트 범위와 개별 호스트 선택 방법을 분명히 했다.

Writer는 실제 적용을 카피 덱의 Marketing message map에 기록했고, 현재 원고의
`copy --check`가 통과했다. 이어 작성자의 감사 기록·선택 이유를 제외한 원고와
사실 자료만 받은 새 검토자가 CLEAN을 반환했다. 검토자는 OMD를 화면 제작과
기존 디자인 검토에 쓰는 프로세스로 이해했으며, 기능·근거·행동의 의미가 일치한다고
판단했다. 같은 카피 해시에 대한 검토 게시와 `copy --review-check`도 통과했다.

이는 독립 텍스트 검토이며 대상 사용자의 선호·이해도 실험은 아니다. 새 문구를
사용한 서체 검증과 화면 반영은 진행 중이다. 최종 화면 승인이나 전환 개선을
주장하지 않는다.
