# Rendered design quality development

This development cycle improves OMD itself. It uses the native OMD runtime, public repository
fixtures, rendered evidence, and independent review. It does not add another design harness.

The target is deliberate composition, typography that accommodates real content, a coherent visual
identity, working interactions, and responsive craft. A particular palette, layout family, or number
of refinement rounds is not the target. The existing
[layout rubric](../evals/layout-composition/graders/blind-rubric.md) supplies the public visual criteria;
the final design-quality contract retains its independent axis floors and desktop/mobile evidence.
An agent review remains a proxy. This cycle has no blind human designer or target-user ratings and
cannot establish human equivalence.

## Live development fixture

The first fixture is the repository's
[NARO engineering landing page](../evals/layout-composition/prompts/01_magnetic-bearing.md).
The supplied fictional demo facts, Korean locale, South Korean market, and engineering audience are
explicit in the run. The task requires the supplied products and metrics, a five-field request form,
and real inspection at 1280×900 and 390×844. It is a public development fixture, not an unseen holdout.

The baseline is commit `5f1fa6f`, built in a separate checkout. The coordinator uses
`gpt-6-astra` at medium effort. Host-invocation overrides use Sol for framing, composition,
production, and detailed review, with Luna for reference acquisition, typography, and glance work.
These are this user's explicit development-run allocations; the package's model-inheritance defaults
remain unchanged.

The first launch stopped before production because its command prefix did not match the host's
canonical process identity. A second launch corrected that prefix and preserved the same task and
baseline code. It published framing and copy, passed the independent copy review, and retained eight
reference captures, all reported as low-signal (0–0.33). It still lacked a valid reference board and
had no production source or rendered page. The experiment was stopped during another reference
repair because the same acquisition failures were recurring; its termination is not a completed
baseline design or a visual comparison result.

Neither a zero launcher exit status nor an intermediate artifact counts as a complete design.
Current final evidence, rendered output, and the actual form path must be inspected.

The first opt-in native image-transport diagnostic terminated with a missing completed evidence
handshake. Bounded child diagnostics exposed a tool-approval setting and an incorrect assumption that
the evidence proxy was the reviewer's immediate child; the native host uses an intermediary.
The remaining fixes pinned the interpreter for the JavaScript Codex entry point and copied evidence
bytes before the broker cleared its private buffer. The native diagnostic then passed with
`gpt-5.6-luna` at low effort: exit code zero, exact expected anonymous alias, observed evidence-tool
call, restricted feature and MCP inventories, and successful authenticated evidence consumption.
The diagnostic establishes image delivery, not aesthetic judgment or visual improvement.
