# Audit and repair loop

Measure the actual build and inspect every requested surface, state and viewport, including
long content and stress cases. Required task, access, safety and evidence defects are never
waived for budget. Accept an initially clean result without inventing a repair round.

Repair the cause, recapture and compare. The same stable defect surviving three real repairs is
reported to the user rather than reworded. A user's broad aesthetic rejection calls for
reconsidering the integrated direction, not a single cosmetic patch.

Finish only through `omd lifecycle finish`; report current verification, debt and limits.
