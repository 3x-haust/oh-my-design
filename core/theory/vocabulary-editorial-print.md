# Cross-domain vocabulary: editorial print

A working solution to "present a lot of text so a reader can navigate it" that existed before the web.
Use this when a design is drifting toward the screen's default answer to that problem.

## What the material already solved

- **The page as a unit of attention.** A spread is composed as one field, not a stack of independent
  sections. What sits opposite what is a deliberate relationship, so a reader's eye is led rather
  than merely permitted.
- **Standing heads and folios.** A running head tells you where you are without being an interface.
  Use it when a long document needs orientation that costs no chrome.
- **The gutter as a real constraint.** Type does not run into the fold, and a column break is a
  decision about reading rhythm rather than a container width.
- **Drop caps, pull quotes, and marginalia as rhythm.** Emphasis is placed at the scale of the page,
  not by making everything slightly louder.
- **Grids that permit asymmetry.** A baseline grid is a floor for text, not a cage for the whole
  composition. A wide image breaking the measure is normal, not an exception to be justified.

## What it offers a screen

- The measure: text set to a comfortable character count, and headings that hold the same measure
  rather than stretching to the container.
- Section transitions that read as a turn of the page rather than a new card.
- Footnotes and side notes as a legitimate way to keep the main line clean instead of hiding detail
  behind progressive disclosure.

## What not to take

The paper metaphor itself. Faux stock, deckled edges, sepia washes, and literal "editorial" serifs
are costume; the useful part is the compositional discipline. A true-white canvas with a real
typographic hierarchy carries the same idea without imitating a material it is not.

## Where it misleads

Print cannot respond, so it has no vocabulary for state, focus, or error. Any flow the reader must
complete needs the screen's own answers for those; take the composition and leave the rest.
