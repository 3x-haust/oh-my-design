# Oh My Design

[![CI](https://github.com/3x-haust/oh-my-design/actions/workflows/ci.yml/badge.svg)](https://github.com/3x-haust/oh-my-design/actions/workflows/ci.yml)
[![npm](https://img.shields.io/npm/v/%403xhaust%2Foh-my-design)](https://www.npmjs.com/package/@3xhaust/oh-my-design)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

**AI that designs like a human.** Type one command with a one-line request. OMD makes a new marketing
page, a new multi-screen product, or a redesign of an existing service, has a cold outside eye look at
it, and stops to show you.

[한국어](README.ko.md)

## One command

| Host | Type |
| --- | --- |
| Pi | `/skill:omd-ultradesign <request>` |
| Claude Code | `/oh-my-design:ultradesign <request>` |
| Codex | `$omd-ultradesign <request>` |

That is the only thing you type. Everything else runs inside it.

## How a run goes

A cycle reads the project and the request, gathers references, makes its own assets, builds the key
screens in the project's real code, and renders them at desktop and phone width. A fresh reviewer that
sees only those captures and one real finished work names the largest sign that a senior designer did
not make it.

Then it stops and shows you where the result is and how to open it, the reviewer's finding, a short
memo of what was learned, and what the next cycle would throw away and rebuild. Reply after the same
command:

- `one more` runs one more cycle and stops again.
- `continue` keeps going until the reviewer finds nothing or cycle 3 is reached.
- `continue without stopping: <request>` starts a request that runs that way from the beginning.

Each cycle starts from a clean conversation that carries only the memo, the surviving assets and the
chosen reference. On Pi the fresh session opens by itself; on Claude Code or Codex, start a new session
(`/clear` or a new chat) and type the command again. Every design choice is OMD's; you decide only
whether to go on.

## Install

### npm

```bash
npm install -g @3xhaust/oh-my-design
oh-my-design install
oh-my-design doctor
```

The unscoped `oh-my-design` package on npm is unrelated. `oh-my-design uninstall` reverses host
installation without deleting a project's `.omd/` records.

### Pi-compatible hosts

```bash
pi install npm:@3xhaust/oh-my-design
```

### Claude Code marketplace

```text
/plugin marketplace add 3x-haust/oh-my-design
/plugin install oh-my-design@omd
```

### From source

```bash
git clone https://github.com/3x-haust/oh-my-design
cd oh-my-design
npm install
node bin/omd-install.ts install
```

## Browser support

OMD prefers its verified `browser-rs` provider on supported Darwin arm64 and Linux x64 hosts and
falls back to Playwright + Chromium. If Chromium is missing, run `npx playwright install chromium`.

## Development

The prompt source of truth is `src/skills/omd-ultradesign/SKILL.md` and `src/agents/`. `skills/`,
`agents/` and `dist/` are generated by `npm run build`; do not edit them directly.

Definition of done for a repository change:

```bash
npx tsc --noEmit
npm run build
npm test
```

Commits use conventional prefixes. Releases and version bumps happen only on explicit request.
